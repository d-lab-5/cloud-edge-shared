# Cloud and Edge

How a D-LAB-5 cloud and its edges work together: linking an edge, keeping its token, syncing knowledge both ways, and a chat that proposes while the person decides.

An **edge** is a small local app (a page, an MCP server, a chat) that a
person, a home server or a robot runs. It links to a **cloud** without a
password, keeps its knowledge in step with the cloud's, and lets the person's
own Claude Code work with it while every change waits for their click.

This site holds its decisions, its roadmap, and
drawings of how it is built and how it works. It is public, and holds no one's data.
